# CashMet

Gestión económica personal con IA (privado, uso propio). Chat-first: escribes gastos en lenguaje natural y la IA actualiza banco, deudas, vehículos, propiedades, nómina, recurrentes y calendario.

- **IA**: Genkit + Gemini Free Tier
- **BD**: Cloud Firestore
- **Frontend**: Vite + React + TypeScript + Tailwind + shadcn/ui
- **PWA**: Instalable en móvil
- **Calendario**: Google Calendar
- **Privado**: Solo 1 usuario, sin publicación/venta
- **País**: Colombia (COP)
